# Give iCloud Drive first-class support

NV will provide provider-aware materialization, status, version-conflict handling, and tested behavior for iCloud Drive only with encryption disabled and `PlainTextFormat` separate-file storage enabled. Plain-text files are the routine cross-Mac representation and provide the intended interoperability with plain-text iOS applications; `Notes & Settings` remains the complete startup and recovery checkpoint. NV derives this behavior from fail-closed provider classification and the actual storage format rather than storing a separate mode bit. RTF, HTML, database-only encryption, and a possible future RNCryptor/FSNotes-compatible format are outside first-class iCloud support. Dropbox and other File Providers remain best-effort because they expose no portable equivalent of iCloud's ubiquitous-item and `NSFileVersion` semantics, though NV still uses compatible local coordination.
