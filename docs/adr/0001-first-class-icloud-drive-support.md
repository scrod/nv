# Give iCloud Drive first-class support

NV will provide tested first-class iCloud Drive support with encryption disabled and `PlainTextFormat` separate-file storage enabled. Plain-text files are the routine cross-Mac representation and provide the intended interoperability with plain-text iOS applications; `Notes & Settings` remains the complete startup and recovery checkpoint. Runtime correctness does not depend on identifying the provider's vendor: positive ubiquitous-item or File Provider evidence establishes a provider-managed root, while explicit item capabilities and actual asynchronous operation results authorize each materialization, status, version, and upload decision. The same plaintext storage contract applies to provider-managed roots, but Dropbox and other File Providers remain best-effort because NV does not validate or promise their complete behavior. `CAP-01` alone selects a session-scoped current-visible fallback over coordinated catalogs and current files; that path may settle visible work but never claims current-known completeness or resolves provider versions. Exact checkpoint upload qualification remains an independent operation and may still authorize receipt-covered cleanup. NV stores neither a provider-brand-derived mode bit nor a persistent capability profile. RTF, HTML, database-only encryption, and a possible future RNCryptor/FSNotes-compatible format remain outside this first-class storage contract.

Normative requirements: `AUTH-01`, `DISC-01`, `CAP-01`, `QUAL-01`.
