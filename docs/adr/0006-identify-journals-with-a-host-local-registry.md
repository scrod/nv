# Identify journals with a host-local registry

Each checkpoint carries a random `checkpointID`; each journal generation carries an independently random, never-reused `journalID` plus the checkpoint base identity it extends and is named `Interim Note-Changes.<journalID>`. Rather than one global pointer or mutable dictionary, exact current-host preferences hold one `NVActiveJournal.<journalID>` entry whose value is the opened rooted directory's bookmark; the integrity-checked journal header remains the single source of its base identity. Bookmark resolution plus descriptor and header validation identifies the journal this Mac may recover, including for a temporary folder that is not the saved default, and only a matching stale bookmark is refreshed.

A fixed per-directory advisory lock must be acquired before a modern instance mutates that directory. Modern journals require no inode lock; only the legacy exact-name journal retains its compatibility lock behavior. Unclaimed journals remain automatically recoverable after ordinary backup restoration and conservative recovery evidence in iCloud. This removes persistent writer identity, writer rotation, and checkpoint ancestry without treating bookmark bytes, a host preference, or a local lock as cross-Mac authority.
