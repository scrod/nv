# Retain inspectable history and use compensating undo

Status: accepted.

Note History, selective recovery, Recently Deleted, inspectable conservative automatic merging and portable causal meaningful-action undo are required segment features. Recovery/undo append new operations; they never rewrite history or manipulate Apple's versions. No expiry, permanent-delete claim, full-history search or exact cross-device typing stack is included initially.

NVConservativeMergeV1 is genesis-pinned and deterministic: complete two-head unique-base inputs, scalar/label rules and narrowly separated exact LF edits; unsupported/ambiguous/rich two-sided cases require review. Derived results retain all input IDs and create no operation on observation. User keeps/edits carry that provenance. The old fuzzy merge helper is not this distributed algorithm.

Current-only edit scope is separate from the causal frontier: ordinary edits/field recovery/compensation retain unresolved alternatives and independent conflict notes. Automatic delete/edit copies are also derived, not irrevocably committed by appearance or projection; later covering Deletes retract only no-longer-eligible automatic views. Retained history and independent user actions survive that change.

ActionRecordV1 and all affected note operations persist together with exact frozen before/after references, one scope, synced action-origin provenance and the maximal causal action parents observed in that scope. Allocate a fresh action origin for each editable collection session, including restart or activation of a rebuilt/copied private store; its within-origin predecessor is provenance/order, not continuation ownership. Undo eligibility is a derived repository view, not ownership by one origin or a mutable shared cursor. A unique causally maximal applicable action may be undone on any Mac; incomparable candidates, competing compensation descendants or unsafe value reversal require Review Undo/Redo. Provider arrival order, wall time, writer sequence and origin locality never choose a candidate.

Meaningful-action undo preserves unrelated current changes, wholly revalidates named groups and records an actual compensation with `undoOf`/`redoOf` and scope parents. A causally later independent action suppresses an earlier redo branch even when that action is later undone/redone; a concurrent action preserves alternatives for review. Undo/Redo preserve the remaining eligible redo sequence. Two Macs may concurrently compensate the same candidate: each revalidates before admission, both immutable actions survive, and competing descendants are reviewed rather than collapsed into a shared pop. Native typing undo remains fine-grained while its local text state is valid and its group implements the selected causal candidate. A later remote action can change eligibility without invalidating native ranges. Retain remaining-effect coverage for captured groups; executable AppKit undo objects/grouping/selections are not synced. Redo follows the actual compensating birth/state, especially fresh restoration after Delete; subsequent Undo targets that actual Redo. Total private-state loss rebuilds durable eligibility from provider action records and loses only native typing state.

The compact per-scope authoring frontier must be ready with current-note startup state. The fuller history/candidate UI index may finish later. A new action names all scope maxima represented by its captured applied causal inputs and earlier pending dependencies; validation rejects omitted maxima. Received-but-unapplied segments and the subset of history rows already loaded cannot redefine those inputs.

Review eligibility is command-relative. Competing leaves in a requested candidate's compensation family remain relevant even across Undo/Redo directions, but a fork in another historical family does not taint a later independent command. Scope-parent observation is ordering, not compensation-family membership or sibling disposition. Reviewed continuation changes only the selected action's actual effect; a now-no-op sibling stays retained and cannot manufacture an Undo/Redo transition. The opposite applicable command and ordinary editing remain available. Equal bodies do not consolidate action IDs or fresh restoration births. V1 retains conservative review rather than adding automatic equivalence, a branch-resolution log or a shared cursor.

History previews are read-only, keyboard accessible and dismissible; late results cannot reopen after dismissal/lock/root change. Body-only recovery preserves current metadata by default; explicit separate historical copies use fresh births, not conflict retry slots. Deleted-note entries derive from commands, not filesystem Trash. Recently Deleted offers Restore alone: creating the fresh birth and its exact source deletion/revision provenance at one local barrier removes that source entry from the default list, without waiting for file projection or upload. Retained restoration evidence, not the new note's continued existence, determines exclusion after restart or validated durable remote receipt. Deleting the restored note later produces a new entry for its fresh birth, never revives the old entry; old deletion/branch history and the restoration link remain inspectable. This is list membership, not history erasure or Apple/conflict disposition. Retained plaintext/encrypted history and its storage/privacy cost must be disclosed; a new-collection current-state export cannot erase old remote copies.

Recently Deleted Notes has its own viewer window; it does not replace the ordinary notes list/search with a deleted-items mode. Ordinary windows share one model/storage session and each note's native/portable undo router while retaining independent presentation state. Remembered per-note cursor ranges use last update wins, including programmatic changes, without making cursor movement a note-history action. Observers cannot multiply mutations/captures; closing or retargeting a view cannot discard or redirect admitted note work. Follow Apple's text-editing contracts, HIG and standard local focus/input handling first. Preserve composition; defer remote editor application to a safe input boundary and then use the existing reconciliation rules. No custom draft buffer, unconditional cancellation, or composition-triggered conflict is required. The actual attachment/lifetime/IME bridge still needs integration tests and does not relax fine-grained undo. Preserve NV's idle/maximum-delay save scheduling independently of semantic undo grouping.

Review Undo/Redo reuses the resolver presentation but retains the invocation's captured command identity, scope, complete maximal candidate set and selected candidate. It first permits candidate selection when causal maxima are incomparable, then previews the exact compensation. Approval records the actual compensation and preserves the remaining causal redo chain; it is not independent historical recovery. The inverse targets affected pre-approval current values, not stale original action values, and still revalidates subsequent changes and the candidate frontier. Explicit Note History recovery and conflict-badge choices keep independent new-action semantics. Cancellation consumes nothing; changed inputs/candidates invalidate consent without retargeting. Review can authorize a disclosed overlapping replacement, not bypass hard admission/identity/generation checks, partially execute a bulk action, or dispose unresolved alternatives. No additional synced undo log, shared cursor or Apple resolution call is introduced.

Normative requirements: HIST-01, DUR-01, REC-01, DELETE-01, CRYPT-01, BACKUP-01.

Native remaining-effect coverage is causal: ordered claims use the latest state;
incomparable claims require review and consume a group only if every maximal claim
is complete. Remaining reversal follows actual Current's represented note lineage.
Both local capture and received-record validation check the first native step
against the writer's unique automatic causal candidate. The
[connected contract](../impl-proposal-5/plan/phase3-connected-record-contract.md)
and [NativeCausalUndoBridge](../tla/NativeCausalUndoBridge.tla) connect these rules
to actual inverses, restart and conditional peer agreement.

Implementation evidence: [native undo experiments](../impl-proposal-5/Native-Undo-Experiments.md) distinguish saved-span bookkeeping and guarded logical compensation from unsupported native range rebasing. Test external changes registered through supported undoable editing paths before considering the coarser handoff; preserve causal eligibility and do not register received history as a duplicate NV action. The suggested Undo Saved Edit fallback after a remote body update is not adopted. The synthetic composition adapter/model tests one mechanism, not its necessity or ordinary AppKit focus behavior. Actual editor/segment integration remains required.
